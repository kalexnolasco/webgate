Backup & restore

Downloads servers, users, groups, webhooks and API keys as one file. Jump-host routes are stored by name, so they survive the move to another instance.

With a passphrase the file is encrypted and carries SSH passwords and private keys, re-encrypted on the target with its own key. Leave it empty for a metadata-only backup — you would then re-enter every credential by hand.
Session recordings are files on disk and are never included — copy them separately.
No passphrase: credentials will be left out of this backup.

Restores from a backup file. Existing users are never deleted, and anything whose name already exists here is skipped.
